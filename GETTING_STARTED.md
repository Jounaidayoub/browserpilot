# Quick Reference - Getting Started

## 🎯 Where Do I Start?

### If you want to contribute or improve the codebase:
👉 **Start here:** [PROTOTYPE_TO_PRODUCTION.md](./PROTOTYPE_TO_PRODUCTION.md)

This is your comprehensive learning guide that will teach you production-quality software development while improving this codebase.

### If you just want to run the extension:
👉 **See:** [README.md](./README.md) - Quick Start section

## 📚 Guide Order (Recommended)

Follow these guides in order for the best learning experience:

1. **[Code Quality Setup](./guides/01_CODE_QUALITY_SETUP.md)** ⏱️ 2-3 hours
   - Install ESLint, Prettier, TypeScript strict mode
   - Get immediate feedback on code quality
   - **Impact:** Instant - catches errors as you type

2. **[Testing Strategy](./guides/02_TESTING_STRATEGY.md)** ⏱️ 1-2 days
   - Set up Vitest for testing
   - Write your first tests
   - Stop being afraid of breaking things
   - **Impact:** Game-changing - enables confident refactoring

3. **[Architecture Documentation](./guides/03_ARCHITECTURE_DOCUMENTATION.md)** ⏱️ 4-6 hours
   - Document the system design
   - Create component catalog
   - Make codebase navigable
   - **Impact:** High - others can understand the code

4. **[Contributing Guidelines](./guides/04_CONTRIBUTING.md)** ⏱️ 2-3 hours
   - Set contribution standards
   - Create welcoming environment
   - Define workflows
   - **Impact:** High for teams

5. **[Refactoring Roadmap](./guides/05_REFACTORING_ROADMAP.md)** ⏱️ Ongoing
   - Identify technical debt
   - Plan improvements
   - Refactor safely
   - **Impact:** Long-term maintainability

6. **[CI/CD Setup](./guides/06_CI_CD_SETUP.md)** ⏱️ 3-4 hours
   - Automate quality checks
   - Set up GitHub Actions
   - Deploy with confidence
   - **Impact:** Catches issues before merge
